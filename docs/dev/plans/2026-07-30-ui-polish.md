## 3. 设计决策（ADR）

### D1：侧栏默认宽度下限 160→256px，拖拽下限 140→200px
- **理由**：logo 条内容（图标 48 + 词标 ≈140 + 折叠钮 24 + padding/gap ≈44）需 ≈256px；worktree 行固定元素 ≈176px，分支名要有意义至少再 +60px。256 同时解 F1 全部症状。
- **否决项**：缩小 logo 图标/词标（损品牌锚点，§3.1 已定 48px）；保持 140 下限（内容物理不可读）。
- **兜底**：宽度 <250px 时词标走 `text-overflow:ellipsis`（优雅降级而非截半字符）；localStorage 旧值 <200 加载时 clamp 自愈。
- **翻盘条件**：用户反馈侧栏挤占终端空间 → 默认下限回调至 232 并接受词标 ellipsis。

### D2：行内按钮 hover-reveal 用 `opacity` 不用 `display`
- **理由**：opacity 保留布局，无 hover 抖动；focus-within 保键盘可达；active 行常显保上下文。
- **否决项**：display:none（可为名称腾出 ≈48px，但 hover 时整行 reflow 抖动，且 T3 后空间已够）。
- **翻盘条件**：用户反馈按钮可发现性差（找不到重命名/删除入口）→ 回退为常驻（只删 CSS 规则即可）。

### D3：Modal 统一走 `.panel-title-bar` 木条标题 + 平涂遮罩 token
- **理由**：规范 §4 本就声称 Modal 用木条标题（实现没跟上）；`backdrop-blur` 在羊皮纸上糊成灰绿色，平涂调暗更贴合像素平涂美学。
- **决策**：新增 `--modal-backdrop` token：light `rgba(58,46,31,0.45)`（wood-shadow 基色暖调变暗）、dark `rgba(9,10,13,0.6)`；删除 `bg-black/50 backdrop-blur-sm`。
- **否决项**：保留平头标题（两种语言并存正是 F4 病根）；遮罩用纯黑 50%（冷灰绿，与暖色体系冲突）。
- **翻盘条件**：若木条标题被认为过重，回退仅改遮罩，标题保留平头但规范 §4 同步修正。

### D4：弹窗按钮统一迁移 `PixelButton`，删除 Sidebar 局部 ModalCancel/ModalPrimary
- **理由**：AGENTS §6 禁 copy-paste；`.btn-pixel` 体系的 disabled/hover/按压态已统一实现；ConfirmDialog 已是 PixelButton，迁移后全 app 弹窗按钮单一口径。
- **决策**：`ModalCancel` 2 处调用点→`PixelButton variant="secondary"`；`ModalPrimary` 1 处→`variant="accent"`；删除 worktree 危险钮→`variant="danger"`；DuplicateProjectsDialog 2 钮同迁；两个局部函数删除。

### D5：文件表格 name 列自适应容器，保留「固定列+横向滚动」设计
- **理由**：`index.css:735-738` 注释明确记录了"table 无显式宽度、调列不互挤"是有意设计，不推翻；只修默认 name 宽度——容器内按 `容器 - mtime(140) - size(100) - actions(104)` 计算，手动拖拽任意列后永久退出自适应。
- **否决项**：`table width:100% + name auto`（违背已记录的设计意图，调 mtime 会挤 name）；缩短 mtime 格式（信息损失，且已有 rtl 左省略兜底）。
- **翻盘条件**：RO 自适应出现抖动/性能问题 → 退化为挂载时一次性测量。

### D6：标题栏 session-id hex 直接移除，不做替代展示
- **理由**：奥卡姆剃刀——面包屑已有完整 cwd，会话身份有 LIVE badge + 侧栏选中态；UUID 前缀对用户零信息。
- **翻盘条件**：用户反馈需要标题栏上下文 → 改显会话名（需从 appStore 取 activeSession.name）。

### D7：不动 `src/tmux/`（冻结），绿条随 pty 迁移解决
- **理由**：pty-engine 计划索引行明确"tmux 相关代码已冻结，只修致命 bug 不加功能"；该计划 §1.2 表明 PtyEngine 下 status bar 问题不存在。
- **翻盘条件**：pty 迁移取消或无限延期 → 单行 `set-option -t <name> status off`（已向用户报备的 freeze 例外）。

- [ ] **Step 2: 重写 Modal.tsx**

```tsx
import { useEffect, useRef, type ReactNode } from 'react'
import { READER_FONT } from '../../utils/fonts'

interface ModalProps {
  open: boolean
  onClose: () => void
  title: string
  children: ReactNode
  /** Max width class, defaults to 'max-w-md' */
  maxWidth?: string
}

export function Modal({ open, onClose, title, children, maxWidth = 'max-w-md' }: ModalProps) {
  const backdropRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!open) return
    const handleEsc = (e: KeyboardEvent) => {
      if (e.key === 'Escape') onClose()
    }
    document.addEventListener('keydown', handleEsc)
    return () => document.removeEventListener('keydown', handleEsc)
  }, [open, onClose])

  if (!open) return null

  const handleBackdropClick = (e: React.MouseEvent) => {
    if (e.target === backdropRef.current) onClose()
  }

  return (
    <div
      ref={backdropRef}
      onClick={handleBackdropClick}
      className="fixed inset-0 z-50 flex items-center justify-center animate-fade-in"
      style={{ background: 'var(--modal-backdrop)' }}
```

```tsx
  // name 列随容器自适应；用户一旦手动拖拽任何列，永久退出自适应（D5）
  const [nameColAuto, setNameColAuto] = useState(true)
  useEffect(() => {
    if (!nameColAuto) return
    const el = fileDragTableRef.current
    if (!el) return
    const fit = () =>
      setColWidths((cw) => {
        const name = Math.max(FM_COL.minName, el.clientWidth - FM_COL.mtime - FM_COL.size - FM_COL.actions - 2)
        return cw.name === name ? cw : { ...cw, name }
      })
    fit()
    const ro = new ResizeObserver(fit)
    ro.observe(el)
    return () => ro.disconnect()
  }, [nameColAuto])
```

```markdown
未经处理的浏览器原生控件是现代圆润风格，与像素体系冲突，必须显式覆写：

| 控件 | 规则 |
|------|------|
| `input[type="range"]` | 统一走 `index.css` 的 pixel range 样式（方块 thumb + 块状 track，见 `.pixel-press` 后样式块），禁止仅设 `accentColor` 了事 |
| Modal 遮罩 | 一律 `var(--modal-backdrop)`（light 暖棕 45% / dark 深黑 60%），禁止 `backdrop-blur`（在羊皮纸上糊成灰绿） |
| `<select>` / 文本输入 | `border-radius: 0`，边框 `var(--border-strong)` |
| checkbox / radio | 允许原生 + `accentColor` 主题化（深度定制收益低，暂不强制） |
```

同步更新 §4 的「Content pattern」行（T7 已删 `.title-bar-path`）与 §14 清单：「Modal 标题统一 `.panel-title-bar` 木条」由表述改为已实现的事实描述。
